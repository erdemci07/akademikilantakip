AKADEMİK İLAN BOTU — MEVCUT REPOYA UYGULANACAK GÜNCELLEME
==========================================================
Hedef depo: github.com/erdemci07/akademikilantakip

Bu zip bir OVERLAY paketidir, yeni bir proje değildir. Dizinleri koruyarak
repo köküne kopyala. Mevcut secrets'ları veya .env dosyasını asla kopyalama.

Değiştirilecek dosyalar:
- src/akademik_ilan_takip/sources.py
- src/akademik_ilan_takip/models.py
- src/akademik_ilan_takip/scanner.py
- src/akademik_ilan_takip/telegram.py
- src/akademik_ilan_takip/cli.py
- config/sources.json

Eklenecek dosyalar:
- tests/test_multisource.py
- docs/KURULUM-VE-SINIRLAR.md

Çalıştır:
  pip install -e '.[dev]'
  python -m pytest -q
  python -m ruff check .
  git add src/akademik_ilan_takip/{sources,models,scanner,telegram,cli}.py config/sources.json tests/test_multisource.py docs/KURULUM-VE-SINIRLAR.md
  git commit -m 'feat: broaden official academic listing discovery and Telegram links'
  git push origin main

Repo farklı branştaysa veya değişmişse güncel haliyle değişiklikleri birleştir;
force push yapma. CI yeşil olmadan üretim taramasını başarıyla çalışmış sayma.
Telegram testinin yeşil olması yalnızca Telegram gönderimini doğrular.
Üretim taraması için FIREBASE_SERVICE_ACCOUNT_JSON secret gereklidir.
